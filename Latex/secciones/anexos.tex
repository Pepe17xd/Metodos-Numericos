\subsection{Repositorio de implementaci\'on y reproducibilidad}

El c\'odigo computacional est\'a disponible en el repositorio p\'ublico \url{https://github.com/Pepe17xd/Metodos-Numericos}. El laboratorio principal es \texttt{simulacion/00\_Proyecto\_Principal.mlx}; \texttt{simulacion/ejecutar\_proyecto.m} permite ejecutar el c\'alculo sin Live Editor. Las funciones auxiliares incluyen la implementaci\'on literal de Gauss--Seidel del laboratorio, la variante eficiente, Gradiente Conjugado, el ensamblaje por diferencias finitas y las verificaciones.

Para reproducir el escenario base, abra el Live Script en MATLAB y presione Run. El modo completo se activa cambiando \texttt{modo\_completo} a \texttt{true}. MATLAB genera directamente los resultados, gr\'aficas y metadatos; no se requieren dependencias externas ni archivos de datos previos.
